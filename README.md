# Clipline

一根挂在屏幕顶部的晾衣绳：截图和剪贴板里复制的东西都会挂上去，点一下复制回来，拖出去直接用。

Clipline 是 [Tendedero](https://github.com/alejandrobujan/tendedero)（MIT）的 fork，在原有「截图自动上绳」的基础上加了剪贴板。名字和图标按原作许可另起，与原作者无关。

## 功能

- **截图自动上绳**：监听系统截图目录，新截图自动挂上并降下绳子提示一下（原版行为）。
- **剪贴板上绳**：复制的文字、图片、Finder 里复制的图片文件都会挂上，**图片（多半是截到剪贴板的截图）和截图一样会弹绳；文字安静挂上不弹绳**，`⌃⌥T` 随时拉下来看。
- **敏感信息打码**：看起来像密钥 / token / 密码的内容（`sk-…`、`ghp_…`、JWT、`password=…`、高熵长串、私钥块等），在绳上和悬停预览里只显示首尾几位；点击复制拿到的仍是原文。密码管理器标记为隐藏的内容直接不挂。
- **悬停放大**：鼠标停在卡片上 0.35 秒，下方弹出大图 / 全文预览。
- **链接卡片**：只复制了一个网址时，卡片显示站点名，右键可直接打开。
- **自己的分组（换绳）**：绳子左端的标签在「最近」和你的分组（常用、密钥、自定义）之间切换，整根绳随之替换并变色。右键「最近」里的文字卡片 › 挂到，或拖到标签上；会先问一个标签（预填复制来源的网站或 app）。分组存在系统钥匙串里，是唯一跨重启保留的内容。条目多了在绳上左右滑动。
- **键盘**：`⌃⌥T`（菜单栏里可改）唤出；`⌘1–9` 复制当前可见的第几张并收起，`Tab`/`⇧Tab` 或再按唤出键换绳，`←`/`→` 滑动一屏，按住 `⌥` 看密钥原文，`Esc` 收起。这些键只在唤出期间生效。
- **全部是临时的**：文字只在内存里；剪贴板图片是临时文件，启动和退出时清空；重启后绳上什么都不留。
- **名额分配**：图片和文字各占一半位置，连续复制文字不会把截图挤掉；同一段文字重复复制只会挪到最新位置。

## 安装

从 Releases 下载 `Clipline-x.y.z.dmg`，拖进「应用程序」即可。菜单栏图标里可以开关「挂上剪贴板」「接管截图」「开机自启」。

## 构建

```sh
scripts/build-app.sh            # 生成 build/Clipline.app（有 Developer ID 时自动签名）
scripts/make-dmg.sh             # 打 dmg；配置了 notary profile 时自动公证并 staple
```

公证凭据一次性配置：

```sh
xcrun notarytool store-credentials clipline-notary --apple-id <Apple ID> --team-id <Team ID>
```

需要 macOS 14 及以上。
